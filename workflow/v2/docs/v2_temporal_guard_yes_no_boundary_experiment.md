# v2 Temporal Guard + Yes/No 边界实验记录

## 1. 实验目的

验证 Yes/No 时序检索是否适合在已有 Temporal Guard v2 阶段之间选择边界候选窗口。

Yes/No 不重新判断完整阶段序列。每个已有边界先取前后 10 秒，划分为 4 个片段；Qwen 对每个片段回答目标转折是否可能出现，并给出概率。得分最高的片段进入原 v2 边界提示词，以 0.5 秒间隔精查。

## 2. 与 Rubric 方法的区别

| 项目 | Rubric 边界 | Yes/No 边界 |
|---|---|---|
| 候选来源 | 十项评价配置和已有阶段 | 额外 Qwen 二分类选择片段 |
| 每个边界调用 | 通常 1 次 | 通常 2 次 |
| 五视频调用 | 20 次 | 41 次 |
| 五视频图片 | 260 张 | 510 张 |
| ±2 秒命中 | 19/20 | 14/20 |
| MAE | 1.125 秒 | 2.025 秒 |

## 4. 结论

Yes/No 能正确覆盖多数边界，但当前版本成本约为 Rubric 的两倍，精度更低。它容易把拿笔准备、继续接触电路或整理前的过渡动作当成正式阶段切换。

当前处理决定：

- 不把 Yes/No 设为默认边界方法；
- 不用 Yes/No 覆盖原 v2 阶段时间段；
- 保留方法说明，用于后续低置信度边界研究；实验代码和模型原始记录不进入公开仓库；
- 默认使用 Rubric 引导边界精修。
